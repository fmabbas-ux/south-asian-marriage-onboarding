# South Asian Marriage Onboarding

**Brand: Dehleez** (دہلیز, "threshold"). Course: **Pehla Saal** (the first year). Game: **Aaghaaz Tamasha** (with **Dono Taraf**, both sides, as its two-player mode).

A public knowledge base for preparing a bride and groom for the **pre-marriage period and the first year of marriage** in South Asian families (Pakistan first, then India, Bangladesh, Sri Lanka, Nepal and the diaspora).

The wedding gets months of planning. The marriage gets none. This project fixes that by laying out every dynamic a new couple will face, in plain situations, and turning it into three products:

1. A **knowledge base** (this repo)
2. A **video course** (YouTube, or a paid website if YouTube monetization is not workable from Pakistan)
3. A **scenario game** where each partner plays the same events from their own side

## The seven dynamics

| # | Source of pressure | Doc section |
|---|---|---|
| 1 | The couple themselves: personalities, habits, expectations | `docs/02-dynamics.md` > D1 |
| 2 | Each partner's parents (both sets) | D2 |
| 3 | Each partner's siblings (sisters-in-law, brothers-in-law, own siblings) | D3 |
| 4 | Extended family: aunts, uncles, cousins, the "khandaan" | D4 |
| 5 | Personal ambitions: career, study, migration, money | D5 |
| 6 | External sources: previous marriages and children, exes, friends, community, social media | D6 |
| 7 | Open slot: new sources are added through `docs/02-dynamics.md` > D7 | D7 |
